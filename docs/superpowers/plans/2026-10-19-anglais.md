# L'anglais dans sillage — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Site, app macOS, terminal et `install.sh` en anglais par défaut, en français pour qui l'utilise.

**Architecture:** Site : une vraie route par adresse (`/`, `/models`, `/download` ; `/fr`, `/fr/modeles`, `/fr/telecharger`), deux mises en page racines, des pages partagées dans `app/_pages` qui reçoivent la langue, deux dictionnaires typés. Rust : un module `src/i18n.rs` (langue d'interface globale, choisie une fois) et des textes doublés `en`/`fr` ; le catalogue des modèles passe ses textes traduits à l'app par la FFI. App macOS : catalogue Xcode `Localizable.xcstrings`, anglais en langue de développement, français traduit ; l'app donne sa langue au moteur au lancement.

**Tech Stack:** Next.js 16.4.2 (App Router, `cacheComponents`), Rust 2021 (clap 4, ratatui, uniffi), Swift / SwiftUI macOS 14+, xcodegen, `xcrun xcstringstool`, `sh` POSIX.

**Spec:** `docs/superpowers/specs/2026-10-19-anglais-design.md`

## Global Constraints

- Deux langues seulement : `en` (défaut) et `fr`. Rien d'autre n'est traduit que l'**interface** : jamais `src/text`, les phonèmes, nombres, sigles, ni la détection de la langue des documents.
- Règle de langue, partout la même : français si le code de langue de l'étiquette — ce qui précède le premier `_`, `-`, `.` ou `@`, sans tenir compte de la casse — vaut `fr` (`fr`, `fr_FR.UTF-8`, `fr-CA`…), anglais sinon. Terminal et `install.sh` : `LC_ALL`, puis `LC_MESSAGES`, puis `LANG`, une variable vide comptant comme absente. App : `Bundle.main.preferredLocalizations.first`.
- Aucun écran ne mélange les deux langues.
- Site : **aucune** réécriture dans `proxy.ts`, aucun segment `[lang]` dynamique. `/install.sh` ne bouge pas. `/modeles` et `/telecharger` redirigent (permanent) vers `/fr/modeles` et `/fr/telecharger`.
- `install.sh` : `--uninstall` affiché ; `--desinstaller` reste accepté.
- Traduction définitive, sans relecture : anglais naturel, même ton court et concret que le français ; typographie française gardée dans le français.
- Restent en français : journaux (`log`, `Logger`), commentaires, messages des tests, README, `docs/`.
- Pas de nouvelle dépendance (ni npm, ni crate, ni SPM).
- **Mise en ligne ensemble** : tout le travail vit sur la branche `feat/anglais` ; elle n'est fusionnée dans `main` qu'au moment de la publication de la version suivante (le site et `install.sh` partent en production depuis `main`). La fusion et le tag demandent l'accord de l'utilisateur.
- Tests macOS : **jamais `xcodebuild test` en local** — compiler seulement (`build-for-testing`) ; les tests Swift tournent sur la CI.
- Commits en français, fin `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```rust
fn etiquettes() {
    for fr in ["fr", "fr_FR.UTF-8", "fr-CA", "fr_BE", "FR_fr"] { assert_eq!(UiLang::from_locale(fr), UiLang::Fr, "{fr}"); }
    for en in ["en_US.UTF-8", "de_DE", "C", "POSIX", "", "francais"] { assert_eq!(UiLang::from_locale(en), UiLang::En, "{en}"); }
}
#[test]
fn ordre_des_variables() {
    // from_env lit par une fonction injectable : from_env_with(|k| …)
    let env = |vars: &[(&str, &str)]| { let v: Vec<_> = vars.iter().map(|(k, x)| (k.to_string(), x.to_string())).collect();
        move |k: &str| v.iter().find(|(n, _)| n == k).map(|(_, x)| x.clone()) };
    assert_eq!(UiLang::from_env_with(env(&[("LANG", "fr_FR.UTF-8")])), UiLang::Fr);
    assert_eq!(UiLang::from_env_with(env(&[("LC_ALL", "en_US.UTF-8"), ("LANG", "fr_FR.UTF-8")])), UiLang::En);
    assert_eq!(UiLang::from_env_with(env(&[("LC_ALL", ""), ("LANG", "fr_FR.UTF-8")])), UiLang::Fr);
    assert_eq!(UiLang::from_env_with(env(&[("LC_MESSAGES", "fr_CA"), ("LANG", "C")])), UiLang::Fr);
    assert_eq!(UiLang::from_env_with(env(&[])), UiLang::En);
}
#[test]
fn surcharge_du_fil() {
    assert_eq!(with_ui_lang(UiLang::En, || tr!("Settings", "Réglages")), "Settings");
    assert_eq!(with_ui_lang(UiLang::Fr, || tr!(en = "{} voices", fr = "{} voix", 3)), "3 voix");
}
```
