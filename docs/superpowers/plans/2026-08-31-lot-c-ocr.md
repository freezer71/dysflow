**Goal:** Qu'une capture d'écran, une photo de page ou un dossier de scans se
lisent comme un PDF — texte reconnu, puis reconstruit par le lot B.

**Architecture:** Un module `src/source/ocr.rs` derrière la feature `ocr`.
Il rend des `Page`, exactement comme `pdf.rs` : toute la reconstruction du lot B
s'applique ensuite sans une ligne de plus. Tesseract est compilé dans le
binaire ; les données de langue y sont embarquées.

**Tech Stack:** Rust 2021, `tesseract-rs 0.4`, `image 0.25`, `arboard 3.6`.

**Spec:** `docs/superpowers/specs/2026-08-30-lecture-pdf-et-images-design.md`

## Global Constraints

- **Aucun `cfg(target_os)`.** Cibles : macOS, Linux x86_64, Linux ARM64.
  `cfg(feature = "ocr")` est en revanche attendu.
- **Le build par défaut reste en secondes.** L'OCR est derrière `--features ocr`,
  comme `audio-cpp`. Sans la feature, une image doit donner un message clair,
  pas une erreur obscure.
- Commentaires et messages en français, noms de tests en anglais descriptif.
- Un commentaire dit **pourquoi**, jamais quoi.
- Pas de `unwrap()` ni `expect()` hors tests.
- Après chaque tâche : `cargo test` et `cargo clippy --all-targets` propres,
  **avec et sans** la feature.
- Le lot B a laissé 288 tests de bibliothèque. Ce nombre ne doit que croître.

build. Ce chemin n'est pas configurable. C'est un coût de **build**, jamais
d'exécution : le binaire distribué reste autonome. Une CI doit mettre ce
répertoire en cache.

```rust
/// Dépose les données de langue dans le cache et rend leur répertoire.
///
/// La taille sert de témoin : réécrire deux mégaoctets à chaque lancement
/// serait inutile, mais un fichier tronqué doit être remplacé.
fn tessdata_dir() -> Result<PathBuf> {
    let dir = dirs::cache_dir()
        .context("répertoire de cache introuvable")?
        .join("sillon")
        .join("tessdata");
    std::fs::create_dir_all(&dir)
        .with_context(|| format!("création de {}", dir.display()))?;
    for (lang, data) in [("fra", FRA), ("eng", ENG)] {
        let file = dir.join(format!("{lang}.traineddata"));
        let current = std::fs::metadata(&file).map(|m| m.len()).unwrap_or(0);
        if current != data.len() as u64 {
            std::fs::write(&file, data)
                .with_context(|| format!("écriture de {}", file.display()))?;
        }
    }
    Ok(dir)
}
```

```rust
impl Ocr {
    /// Ouvre un moteur, données de langue comprises.
    pub fn new() -> Result<Self> {
        let dir = tessdata_dir()?;
        let api = tesseract_rs::TesseractAPI::new();
        api.init(dir.to_string_lossy().as_ref(), LANGUAGES)
            .map_err(|e| anyhow::anyhow!("ouverture du moteur de reconnaissance : {e}"))?;
        Ok(Self { api })
    }

    /// Reconnaît le texte d'une image déjà décodée.
    ///
    /// L'image est ramenée en niveaux de gris : Tesseract y travaille mieux, et
    /// la couleur n'apporte rien à de la reconnaissance de texte.
    pub fn read(&self, image: &image::DynamicImage) -> Result<Page> {
        let grey = image.to_luma8();
        let (width, height) = grey.dimensions();
        self.api
            .set_image(grey.as_raw(), width as i32, height as i32, 1, width as i32)
            .map_err(|e| anyhow::anyhow!("chargement de l'image : {e}"))?;
        let text = self
            .api
            .get_utf8_text()
            .map_err(|e| anyhow::anyhow!("reconnaissance du texte : {e}"))?;
        Ok(Page {
            lines: text.lines().map(|l| l.trim_end().to_string()).collect(),
        })
    }
}

/// Reconnaît le texte d'un fichier image.
pub fn pages(path: &Path) -> Result<Vec<Page>> {
    let image = image::open(path)
        .with_context(|| format!("lecture de l'image {}", path.display()))?;
    Ok(vec![Ocr::new()?.read(&image)?])
}
```

```rust
/// Découpe un nom en fragments comparables : les chiffres comptent comme des
/// nombres, pas comme des lettres.
fn natural_key(name: &str) -> Vec<Natural> {
    let mut out = Vec::new();
    let mut text = String::new();
    let mut digits = String::new();
    for c in name.chars() {
        if c.is_ascii_digit() {
            if !text.is_empty() {
                out.push(Natural::Text(std::mem::take(&mut text)));
            }
            digits.push(c);
        } else {
            if !digits.is_empty() {
                // Un nombre trop long pour tenir dans un u64 reste du texte.
                match digits.parse() {
                    Ok(number) => out.push(Natural::Number(number)),
                    Err(_) => out.push(Natural::Text(digits.clone())),
                }
                digits.clear();
            }
            text.push(c.to_ascii_lowercase());
        }
    }
    if !text.is_empty() {
        out.push(Natural::Text(text));
    }
    if !digits.is_empty() {
        match digits.parse() {
            Ok(number) => out.push(Natural::Number(number)),
            Err(_) => out.push(Natural::Text(digits)),
        }
    }
    out
}

/// Reconnaît le texte de toutes les images d'un dossier, dans l'ordre.
pub fn directory_pages(dir: &Path) -> Result<Vec<Page>> {
    let mut files: Vec<PathBuf> = std::fs::read_dir(dir)
        .with_context(|| format!("lecture de {}", dir.display()))?
        .filter_map(|entry| entry.ok().map(|e| e.path()))
        .filter(|path| {
            path.is_file()
                && std::fs::read(path)
                    .map(|bytes| matches!(super::kind::sniff(&bytes), super::Kind::Image))
                    .unwrap_or(false)
        })
        .collect();
    if files.is_empty() {
        anyhow::bail!("{} ne contient aucune image lisible", dir.display());
    }
    files.sort_by_key(|path| {
        natural_key(&path.file_name().unwrap_or_default().to_string_lossy())
    });

    // Un seul moteur pour tout le dossier : son ouverture coûte plus que la
    // lecture d'une page.
    let engine = Ocr::new()?;
    let mut pages = Vec::with_capacity(files.len());
    for file in files {
        let image = image::open(&file)
            .with_context(|| format!("lecture de l'image {}", file.display()))?;
        pages.push(engine.read(&image)?);
    }
    Ok(pages)
}
```

**Attention** : `sniff` ne lit que les premiers octets ; lire le fichier entier
pour cela serait coûteux sur un dossier de scans. Si le test est lent,
remplacez `std::fs::read(path)` par une lecture des seize premiers octets, à
l'image de `kind::of_path`.

```rust
/// Reconnaît une image donnée en pixels bruts, comme le presse-papiers la rend.
pub fn read_rgba(pixels: &[u8], width: u32, height: u32) -> Result<Page> {
    let buffer = image::RgbaImage::from_raw(width, height, pixels.to_vec())
        .context("les pixels ne forment pas une image de cette taille")?;
    Ocr::new()?.read(&image::DynamicImage::ImageRgba8(buffer))
}
```

Dans `src/source/mod.rs` :

```rust
/// Lit le presse-papiers : son image reconnue, ou son texte tel quel.
///
/// L'image passe d'abord : un texte copié depuis un PDF verrouillé arrive
/// souvent aussi en image, et c'est alors elle qui porte le contenu.
#[cfg(feature = "ocr")]
pub fn clipboard() -> Result<String> {
    let mut board = arboard::Clipboard::new().context("accès au presse-papiers")?;
    if let Ok(image) = board.get_image() {
        let width = image.width as u32;
        let height = image.height as u32;
        let page = ocr::read_rgba(&image.bytes, width, height)?;
        return Ok(layout::to_markdown(&[page]));
    }
    let text = board
        .get_text()
        .context("le presse-papiers ne contient ni image ni texte")?;
    Ok(text)
}
```
